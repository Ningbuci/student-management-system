\# 学生管理系统 (C语言)



基于 C11 的控制台学生管理系统，支持增删改查、排序、统计及文件持久化。



\## 功能

\- 添加、删除、修改、查找学生

\- 显示全部学生

\- 按学号升序 / 按成绩降序排序

\- 统计人数、平均分、最高分、最低分

\- 数据保存到文件 / 从文件读取
